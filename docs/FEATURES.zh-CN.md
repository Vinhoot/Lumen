# Lumen · 功能介绍

> 把散落在硬盘各处的图片和视频，收进一个能看、能筛、能打标签的本地媒体库。
>
> 一句话：**给摄影师 / 收藏党 / 素材整理者的本地"私人图库"**——
> macOS 液态玻璃的观感，Windows 原生的轻量，数据全部留在自己机器上。

---

## 一、它解决什么问题

素材散在十几个文件夹里，找一张图只能靠回忆路径；文件管理器缩略图慢、不能打标签、
视频没法直接看。Lumen做的事很聚焦：

- **建立索引，不搬动文件** —— 原片留在原地，库里记路径、元信息、标签；
- **三种维度随手筛** —— 文件夹、作者、标签，还能按日期 / 类型重新分组；
- **看片不用跳出去** —— 图片和视频在应用内直接预览，视频可拖进度条；
- **整理有反馈** —— 批量打标签、批量归属作者，右键即达。

## 二、界面导览

```
┌──────────────────────────────────────────────────────────────┐
│ ● ● ●   ☰   Lumen   [工作|生活] ＋      🏷标签   ▦ ☰ [搜索] … │  ← 标题栏
├────────────┬─────────────────────────────────────────────────┤
│ 库         │  全部媒体 · 27 项            [按文件夹 ▾]        │
│  全部媒体  │  ┌────┬────┬────┬────┐                          │
│  图片      │  │    │    │    │    │   按文件夹分组            │
│  视频      │  └────┴────┴────┴────┘                          │
│ 待整理     │                                                  │
│  无标签    │      （标签在标题栏正中，点开为玻璃面板）          │
│  未识别作者│                                                  │
│ 文件夹     │                                                  │
│ 作者       │                                                  │
├────────────┴─────────────────────────────────────────────────┤
│ ● 就绪    [扫描进度]              [缩略图滑块]  [备份]        │  ← 状态栏
└──────────────────────────────────────────────────────────────┘
```

侧边栏四个分区（库 / 待整理 / 文件夹 / 作者）**各自独立滚动**，分隔条还能上下拖动，
按你的习惯分配高度；**每个分区标题行一键收起 / 展开**（带 macOS 手风琴动画，按工作区记忆），
文件夹树还支持**整棵全部展开 / 收起**，分支再多也不挤。
标签移到了**标题栏正中**：点「标签」展开玻璃面板，筛选、搜索、新建都在那里，给左侧文件夹树腾出整块空间。

## 三、核心功能

### 1. 导入：两种入口，一条流水线

| 方式 | 说明 |
| --- | --- |
| 添加文件 | 手动多选一批图片 / 视频，适合"只想收这几张" |
| 扫描文件夹 | 递归扫描整个目录树，记住扫描源，下次可一键重扫 |

- **扫描源管理**：点「重新扫描」弹出目录清单，勾选要重扫的目录、添加新目录、
  移除不再关注的目录，也能「全部重扫」；
- **后台多线程**：扫描不阻塞界面，状态栏实时显示进度和数量；
- **自动过滤杂图**：最大边小于 224px、或体积极小的图标 / 表情 / UI 截图不进库，
  避免几千张缓存图把库撑乱（手动添加的文件不受限制）。

### 2. 浏览：网格 + 列表，缩略图随你调

- **网格视图**：等宽卡片、圆角缩略图、悬停微抬，长视频带时长徽标；
- **列表视图**：Finder 风格，七列信息——缩略图 / 文件名 / 作者 / 标签 /
  类型·时长 / 尺寸 / 大小 / 修改日期，可读性优先；
- **缩略图尺寸 140–360px 无级调节**，状态栏滑块或右键「缩略图大小」都能改；
- **懒加载 + 失败重试**：滚到哪生成到哪，几百张大图也不会一次性吃满内存；
- **大库分页浏览**：首屏 300 项，滚动到底自动续页；超过 3000 项转为「点击继续加载」，
  5 万级库里滚动依旧跟手，打标签等操作也不会把视图弹回顶部。

### 3. 分组：一个下拉，五种视角

- **按文件夹**（默认，还原你的目录结构，树形可折叠）
- **按日期**，粒度可选 **年 / 月 / 日**
- **按作者**（谁拍的归一堆）
- **按类型**（图片 / 视频分家）
- **不分组**（纯粹的时间流）

选择会被记住，下次打开还是你习惯的那个视角。

### 4. 搜索与筛选：三条路，可叠加

- **搜索框**支持切换范围：**文件名 / 作者 / 标签**，输入后 250ms 防抖自动触发；
- **侧栏筛选**：库（全部 / 图片 / 视频）、文件夹、作者；
- **标签面板在标题栏正中**：点 chip 直接叠加 / 移除筛选，**点多个标签 = 同时满足（AND）**——
  "既要人像又要精修"一步到位；面板里还能即时搜索、一键「只看无标签」；
- **待整理**两个专用视图：**无标签**（还有哪些没归类）、
  **未识别作者**（系统拿不准是谁的，等你确认）。

### 5. 作者识别：能自动就自动，拿不准就问你

依次尝试：EXIF `Artist` → XMP `dc:creator` → 视频元数据 → 同名 sidecar 文本 →
文件夹名 / 文件名里的中文人名。

- 认出来的直接归位；认不出来的进「未识别作者」视图，**右键批量归属**，
  不用一个个点开看；
- 作者可以新建、重命名；删除作者只是把文件退回"未识别"，不动磁盘。

### 6. 标签：带颜色的自由维度

- 自定义名称 + 颜色（8 色预设，彩色胶囊收在标题栏正中的标签面板里）；
- **三态勾选**：✓ 表示所选全部已有、— 表示部分已有，点一下即增 / 删；
- 三种添加方式：右键子菜单、底部批量条、标签面板「新建标签…」；
- 标签 chip 右键：只看此标签、叠加筛选、重命名、改颜色、删除（删标签只摘掉标记，不影响文件）。

### 7. 选择与批量操作

单击选中、**Ctrl** 点加选、**Shift** 点区间、**Ctrl+A** 全选、
在空白处**按住左键框选**（橡皮筋）、**Esc** 取消。

选中 ≥1 项，底部浮出批量条：**标签… / 设为作者… / 打开 / 删除 / 取消选择**。
窄窗口下自动收成纯图标，条本身固定居中，不随选中数量上下跳动。

### 8. 右键菜单：每个角落都有该有的动作

菜单是应用内自绘的玻璃面板，子菜单向右展开，支持完整键盘操作
（↑↓ 移动、→ 进子菜单、Enter 执行、Esc 关闭）。

| 右键位置 | 能做什么 |
| --- | --- |
| 媒体卡片 / 列表行 | 打开、预览、在系统中打开、资源管理器中显示、标签 ▸、作者 ▸、复制文件名 / 完整路径、从库中移除（保留文件）、移到回收站 |
| 内容区空白 | 网格 / 列表切换、分组方式 ▸、缩略图大小 ▸、全选、取消选择、添加文件、扫描文件夹、重新扫描 |
| 库（全部 / 图片 / 视频） | 快速切库、导入类操作、**媒体库统计**（各类数量一览） |
| 文件夹树节点 | 只看此文件夹、叠加筛选、重扫该目录、在系统中打开 |
| 作者 | 只看此人、重命名、删除作者 |
| 标签 | 只看此标签、叠加到当前筛选、重命名、改颜色 ▸、删除标签 |
| 状态栏备份按钮 | 立即备份 / 历史备份与恢复 |

### 9. 应用内预览：图片和视频都不用跳出去

双击或按**空格**进入全屏预览：

- 顶栏显示文件名、作者、尺寸 / 时长 / 大小等元信息；
- **视频流式播放**（HTTP Range 分段读取），可以拖进度条、暂停、调音量；
- **← / →** 在当前位置前后切换，不用退出重进；
- 支持「在系统中打开」和「移到回收站」，也可点背景或 Esc 关闭。

### 10. 工作区：把不同来源彻底隔开

顶部胶囊切换「工作 / 生活」等任意工作区，**每个工作区是独立的库**——
标签、作者、索引、备份互不干扰，切换时交叉淡入。适合把"客户项目"和
"个人收藏"分开管，或按年度归档。

### 11. 备份与恢复：小、快、能退回去

- 只备份**索引库**（作者 / 标签 / 设置），gzip 压缩，通常几百 KB；
- **退出时自动备份**：距上次超过 2 分钟且库有改动才写，不做无意义快照；
- **手动备份**：点状态栏「备份」，每次都新建一份；
- 每个工作区保留最近 **5 份**，更早的自动清理；
- 历史列表标明 **手动 / 自动 / 恢复前**，附完整日期时间和大小，一键恢复；
- 恢复前自动先存一份「恢复前」快照，恢复错了还能退回来。

### 12. 外观与窗口手感

- **深色 / 浅色双主题**，一键切换，跟随你的使用场景；
- **macOS 液态玻璃**质感：面板半透明 + 44px 背景模糊 + 细高光边；
- **无边框自绘窗口**：左上角红绿灯（关 / 最小化 / 最大化），标题栏拖窗，
  四边八向拖拽缩放；
- **880px 到全屏**全程可用：窗口变窄时侧栏自动转为抽屉，点击遮罩收起；
- 图标统一 **18px 视觉框 + 1.7 描边**的光学基准，肉眼对齐而非几何对齐。

## 四、快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl + F` | 聚焦搜索框 |
| `Ctrl + A` | 全选当前列表 |
| `Enter` | 打开选中项（系统默认程序） |
| `Space` | 预览选中项 |
| `Delete` | 移到回收站（需确认） |
| `Esc` | 依次关闭：预览 → 弹层 / 菜单 → 取消选择 |
| `←` / `→` | 预览中切换上一项 / 下一项；菜单中收起 / 展开子菜单 |
| `↑` / `↓` | 菜单项移动 |
| 单击 / `Ctrl` 点 / `Shift` 点 | 单选 / 加选 / 区间选 |
| 点标题栏「标签」chip | 叠加 / 移除标签筛选（多选 = AND） |

## 五、数据与隐私

- **纯本地**：不联网、不登录、不上传，没有任何统计数据；
- **不碰原文件**：只读元信息，删除走 Windows 回收站（可还原），
  也可以选择仅"从库中移除"而保留磁盘文件；
- **内嵌服务仅本机**：页面与视频流走 `127.0.0.1` 随机端口，外部无法访问；
- **绿色便携**：数据都在程序目录 `data\`，整个文件夹拷走就能换机器；
  卸载 = 删文件夹，注册表零残留。

## 六、技术规格

| 项目 | 说明 |
| --- | --- |
| 运行环境 | Windows 10/11 64 位 + WebView2 运行时 |
| 技术栈 | Python 3.12 + pywebview(WebView2) + SQLite；前端原生 HTML/CSS/JS，无构建步骤 |
| 打包形态 | PyInstaller onedir 绿色版，约 130 MB（含 ffmpeg 抽帧库） |
| 索引规模 | 十万级条目下筛选与分组仍在毫秒级（SQLite 索引 + 分页查询） |
| 扫描性能 | 8–16 线程并发读元数据，边扫边入库、可中断 |
| 备份体积 | 单份通常 100–600 KB（只含索引，不含缩略图与原片） |
| 许可证 | MIT（可自由使用、修改、分发） |
